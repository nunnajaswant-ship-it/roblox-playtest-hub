01 / The problem
"the obby is broken"
"the shop doesn't work" Actual feedback, every single update
Missing build

Which version? v0.5.0 or the one from yesterday? Without a build, a report describes a game that no longer exists.

Missing reproduction

No steps, no device, no expected result. A developer spends the first twenty minutes asking questions, not fixing.

Missing owner

It scrolls away in Discord. Nothing is assigned, nothing is verified, and the same bug is reported three times.

The missing artifact is not a chat. It is a reproducible report, with a severity a team can defend and an owner who is accountable.

02 / The gap

Every existing tool solves one third of this

ToolWhat it doesWhat it still leaves to a human

Google Formcollects fieldswhether the report is reproducible at all; no triage, no state
Jira / Trelloworkflow statesplaytest context, build discipline, severity that means something
Coding agentsfast editsjudgement, isolation, and any guarantee that main still works
Our bet

The unit of work is not a message or a ticket. It is a report that survives the handoff, moving through a pipeline where every stage produces evidence the next stage can trust.

03 / The loop

One loop, six artifacts

01 Play a real build, in the browser, with two versions side by side
→
02 Report build, area, expected, actual, steps, evidence
→
03 Pipeline reproducibility, severity, confidence, route
→
04 Agent team five scoped agents on branch fix/PH-<ref>
→
05 Human gate a person marks Verified, or nothing merges
→
06 Release main moves; the old build stays playable

Each step hands the next one an artifact: a report, a score, a work order, a patch, a test result, an approval.

04 / Intake

A report a stranger can reproduce

Required fields
  • Build and version the tester actually played
  • Area: stage, shop, HUD, checkout
  • Expected vs actual, in the tester's own words
  • Ordered reproduction steps
Honesty rails
  • Severity has written definitions, so two testers agree
  • Screenshot link is validated as http(s), never rendered as HTML
  • Duplicate suggestions are advisory and always explain themselves
  • No steps means the pipeline asks a question instead of guessing
// every field is validated by one pure function, // used by the form AND the import path validateReport(draft) -> { title?: "...", actual?: "..." }
05 / Triage

Severity is computed, printed, and reproducible

// deterministic. no model call. no network. score = 30 base + category shop 20, data 18, obby 16, gameplay 14, perf 10, ui 8 + frequency always 20, often 14, sometimes 8, once 3 + platform mobile 10, console 8, pc 6 + impact robux, lost, save, crash... +8 each, max 24 85+ blocker 70+ high 52+ medium <52 low
Why this wins points

A judge can watch the same report score the same number twice, offline. No hidden model, no variance, no "the AI decided".

Confidence is separate

Evidence quality unlocks routing. Two or more steps, a screenshot and a detailed actual raise confidence. Below 60% the pipeline refuses to route and asks the tester one specific question.

06 / Routing

Who acts on it is an explicit decision

ConditionRouteWho acts
confidence < 60%Needs more informationthe tester, with one specific question
blocker or highHuman requireda person decides the approach before code changes
tester vs pipeline differ by 2 levelsHuman requireda person breaks the tie
mediumAgent repair + human reviewagent team, then a person checks
lowAgent repair, autoagent team on a branch

The pipeline never overrules a tester silently. Disagreement escalates to a person, not to a bigger model.

07 / Novelty

Three claims we can defend

01

Explainable triage

Every severity shows its arithmetic and its confidence. Same report, same score, every time, with no network dependency.

02

Branch-isolated repair

Agents work only on fix/PH-<ref>. The main line is not theirs to touch, and the previous build stays playable exactly as shipped.

03

A human owns the merge

The reviewer agent blocks unless a person has marked the report Verified. Automation proposes; a human disposes.

The novelty is not "an AI fixes bugs". It is a pipeline where every handoff is auditable: report, score, route, work order, patch, self-test, approval.

09 / Safety

Nothing reaches main by accident

AReportPH-101, scored, routed
→
BWork orderfix/PH-101, scope fixed
→
CPatchbranch only, tests added
→
DSelf-testrepro + regression pass
→
EHuman Verifiedthe only key to main
Version safety, concretely

Build 0.5.0 and 0.5.1 both ship in the app. The old build is always one click away, so "we did not break the previous version" is a thing you can check, not a promise.

Rollback is trivial

Because a fix is a branch, reverting it restores the previous build exactly. There is no untangling of a half-merged agent edit.

12 / Tech stack

Small stack, chosen for reasons

Chosen
React 19.3one page, no routing library needed
TypeScript 7the data model is the product
Vite 8.3instant dev, one-command static build
Vitest 5domain logic tested without a browser
localStoragebehind a StorageAdapter interface
Canvas 2Dthe test build, no engine dependency
Rejected, and why
  • Next.js - no server, no SEO, no routing problem to solve
  • Supabase - auth and network for a one-day build
  • Tailwind - ~30 design tokens, not a utility system
  • Component library - makes it look like every admin panel
  • Chart library - two shapes, hand-rolled SVG

No backend means no auth screen, no deploy secrets, and a demo that runs offline on the venue laptop. The adapter seam is the whole migration story.

13 / Architecture

Dependencies point one way

views/ overview, test build, triage, reports, pipeline, readiness, data components/ board, cards, form, drawer, toasts state/ reducer + context (Fast Refresh safe) pipeline/ triage.ts: score, route, work order domain/ types, similarity, readiness, validation, filters <- pure data/ repository -> StorageAdapter browser localStorage
The seam

interface StorageAdapter {
  read(key): string | null
  write(key, value): void
  remove(key): void
}

A backend is one new class. No view changes.

Why it matters

domain/ has no React and no browser API. That is why 41 tests run in under half a second and why the same validation runs in the form and on import.

14 / Scope

What is real, and what is scoped

Real, and demonstrable
  • intake, validation, duplicate detection
  • deterministic severity and confidence
  • routing, work orders, branch isolation
  • five agent prompts, one executed live
  • human Verified gate, persistence, export
Scoped for the day, and stated
  • pipeline runs in-browser, not behind a server
  • agents are CLI-invoked, not orchestrated by a queue
  • single browser, single device; no multi-user sync
  • test build defects are planted so the demo repeats
  • no Roblox API ingestion yet

We would rather show a narrow thing that is true than a wide thing that is a slide.
